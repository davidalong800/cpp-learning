## 1. 🔴 Скелет программы — знаю наизусть

```cpp
#include <iostream>   // библиотека ввода-вывода

int main() {          // главная функция — точка входа
    // код программы
    return 0;         // 0 = программа завершилась успешно
}
```

🔴 Я знаю, что:

- программа всегда начинается с `int main()`;
- тело функции пишется в фигурных скобках `{ }`;
- каждая команда заканчивается `;`;
- `return 0;` — завершающий штрих, ноль означает успешное завершение;
- после `#include` точка с запятой НЕ ставится, а после команд внутри `main` — ставится всегда.

🟡 Если забыть `;`, компилятор укажет на строку — часто на следующую, а не на ту, где забыл.

## 2. 🔴 Компиляция и запуск — умею

```bash
g++ hello.cpp -o hello    # собрать: из hello.cpp получаю программу hello
./hello                   # запустить (macOS / Linux)
hello.exe                 # запустить (Windows)
```

🔴 Я знаю, что:

- `-o имя` задаёт имя готовой программы;
- без `-o` программа назовётся `a.out` (macOS/Linux) или `a.exe` (Windows);
- терминал читает `./` как «искать программу в текущей папке».

🟡 Когда `g++` выдаёт много ошибок, я смотрю ПЕРВУЮ: остальные часто её следствие и исчезнут сами.

## 3. 🔴 Вывод на экран: `std::cout` — умею

```cpp
std::cout << "Текст" << "\n";
std::cout << "Имя: " << name << "\n";
```

🔴 Я знаю, что:

- `<<` можно вызывать цепочкой: `std::cout << "a" << b << "c";`
- `"\n"` — перенос строки, и для переноса беру именно его;
- текст пишется В кавычках, а имена переменных — БЕЗ кавычек;
- `"name"` выведет слово `name`, а `name` выведет значение переменной.

🟡 Я понимаю, что `std::endl` — тоже перенос, но ещё и сбрасывает буфер, поэтому работает медленнее и в учебном коде не нужен.

🟡 Я понимаю, что пробелы внутри строки важны: `"! Тебе "` и `"!Тебе "` дадут разный результат.

## 4. 🔴 Переменные и типы — умею

```cpp
std::string name = "Давид";   // строка
int age = 16;                 // целое число
```

| Тип | Что хранит | Примеры |
|---|---|---|
| `int` | целое число | `16`, `-5`, `2025` |
| `double` | дробное число | `3.14`, `-0.5` |
| `char` | один символ | `'A'`, `'!'` |
| `bool` | истина / ложь | `true`, `false` |
| `std::string` | строка (текст) | `"Давид"` |

🔴 Я знаю, что:

- объявление выглядит так: `тип имя = значение;`
- имя переменной — латиница, без пробелов, осмысленное (`age`, а не `a` или `x1`);
- для `std::string` нужен `#include <string>`.

🟡 Я понимаю, что `char` пишется в ОДИНАРНЫХ кавычках и содержит ровно один символ, а `std::string` — в ДВОЙНЫХ и может содержать сколько угодно символов.

## 5. 🔴 Ввод с клавиатуры: `std::cin` — умею

```cpp
std::string name;
int age;

std::cout << "Как тебя зовут? ";
std::cin >> name;

std::cout << "Сколько тебе лет? ";
std::cin >> age;
```

🔴 Я знаю, что:

- переменная объявляется БЕЗ значения, а потом в неё кладётся ввод;
- `std::cin >> x` читает ДО первого пробела.

🟡 Я понимаю, что поэтому имя «Давид Кузнецов» через `cin >> name` прочитается только как «Давид», и что для строки с пробелами нужен `std::getline(std::cin, name)` — это тема дня 2.

🟡 Я понимаю, что `cout` без `\n` оставляет курсор на той же строке — так и получается приглашение «Как тебя зовут? », после которого ввод идёт на той же строке.


🟡 Я знаю, что выражение можно вычислять прямо внутри `cout` и отдельная переменная для этого не нужна.

🟡 Я помню, что `7 / 2` даст `2`, потому что оба числа целые, а `7.0 / 2` даст `3.5`.

## 7. 🔴 Пространство имён `std::` — знаю

- все стандартные имена живут в `std`: `std::cout`, `std::cin`, `std::string`;
- 🔴 я пишу `std::` явно;
- 🔴 я НЕ использую `using namespace std;` — в реальных проектах это приводит к конфликтам имён.

🟡 Если написать `cout` без `std::`, компилятор скажет «cout was not declared».

## 10. 🟡 Почему важен пробел — понимаю

```cpp
// было — ! слипается со словом:
std::cout << "Привет, " << name << "!" << "Тебе " << age << " лет.\n";

// стало — пробел внутри строки:
std::cout << "Привет, " << name << "! Тебе " << age << " лет.\n";
```

🟡 Разница только в одном пробеле внутри `"! Тебе "` — но именно он отделяет `!` от `Тебе`.

## 11. 🔴 Эталонный код дня 1 — пишу по памяти

Файл: `01_basics/age_input.cpp`

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "Как тебя зовут? ";
    std::cin >> name;

    std::cout << "Сколько тебе лет? ";
    std::cin >> age;

    std::cout << "Привет, " << name << "! Тебе " << age << " лет.\n";

    return 0;
}
```

Вывод программы:

```

Сколько тебе лет? 16
Привет, Давид! Тебе 16 лет.
Через 10 лет тебе будет 26.
```
